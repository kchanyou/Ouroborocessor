## 사용 허가

저작권자는 Ouroborocessor 무료 공개 베타를 개인·교육·업무·상업 목적의 원고 작성에 사용할 수 있는 비독점적이고 양도 불가능한 사용권으로 제공. 사용자 본인이 소유하거나 정당하게 사용할 수 있는 장치에 설치할 수 있으며 장치 수 제한 없음.

## 허용 범위

- 개인·교육·업무·상업 목적의 원고 작성과 내보내기
- 사용자가 소유하거나 정당하게 사용할 수 있는 장치에 설치
- 개인 백업 목적의 원본 설치 파일 복사

## 제한

- 소프트웨어 또는 설치 파일의 유료 재판매
- 앱 이름·서명·저작권 표시를 변경한 재배포
- 저작권자의 사전 허락 없는 수정본·결합 상품의 배포
- 관련 법률이 허용하는 범위를 넘는 보호 장치 우회
- 악성 코드 결합 또는 제3자 권리 침해 목적의 이용

## 공개된 소스 코드

공개 저장소의 소스 코드는 검토와 보안 확인을 위해 제공. 저작권자의 사전 서면 허락 없이 소스 코드, 수정 빌드 또는 파생 제품을 재배포·재판매·재허가할 권리는 부여하지 않음. 저장소 공개만으로 오픈소스 사용권이 성립하지 않음.
