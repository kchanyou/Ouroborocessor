## 주요 변경

- **백업·복구 센터**: 프로젝트 전체 수동 백업, 선택형 자동 백업, 원고 미리보기와 새 프로젝트로 복원을 지원합니다. 백업 중 원본 변경을 감지하면 불완전한 백업을 폐기합니다.
- **앱 전체 색상 적용**: 세피아·밤·사용자 지정 색상을 원고뿐 아니라 사이드바, 도구막대, 메뉴에도 적용합니다.
- **사용자 지정 창 분할**: 좌우·상하 방향을 직접 선택하고 경계선을 움직여 비율을 조절할 수 있습니다. 창이 좁아져도 방향이 바뀌지 않으며 프로젝트별 배치를 기억합니다. 현재는 두 개 편집 창을 지원합니다.
- **분할 조작 개선**: 좁은 창의 메뉴 잘림, 탭 드래그 취소, 키보드 포커스 복귀를 보완했습니다.
- **편집·저장 안정성**: 찾기·치환과 실행 취소, 한글 조합 입력, 줄바꿈 형식에 따른 이미지·장면 위치 계산, 프로젝트 전환 전 저장 처리를 개선했습니다.
- **접근성**: 명령 팔레트와 설정 대화상자의 포커스, Escape·Enter 키 동작을 개선했습니다.
