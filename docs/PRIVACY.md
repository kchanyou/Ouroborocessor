# Ouroborocessor 개인정보 처리 안내

시행일: 2026-09-29  
운영자: 김찬영(Kim Chanyoung)  
개인정보·지원 문의: `qurioturio@gmail.com`

이 안내는 Ouroborocessor 0.1 무료 공개 베타의 현재 구현과 운영 범위에 적용.

## 앱 안의 데이터 처리

- 계정 생성 없음
- 사용 분석·광고 SDK 없음
- 자동 충돌 보고 전송 없음
- 클라우드 동기화 없음
- 원고 본문, 이미지, 레퍼런스 카드, 메모, 복구 초안은 사용자가 선택한 로컬 프로젝트 폴더 또는 기기의 앱 저장소에 보관
- 글자 크기, 줄 간격, 언어, 창 배치 등의 설정은 기기의 앱 저장소에 보관

현재 앱 자체는 원고나 사용 통계를 운영자에게 자동 전송하지 않음.

## 지원 문의

사용자가 이메일로 지원을 요청할 때 이메일 주소, 문의 내용, 사용자가 자발적으로 첨부한 파일이나 진단 정보를 처리할 수 있음. 처리 목적은 문의 확인, 답변, 오류 조사와 서비스 개선. 문의 처리에 필요한 기간 동안 보관한 뒤 지체 없이 삭제하며, 법령상 보존 의무가 있는 경우 해당 기간 적용.

원고 또는 민감한 개인정보가 포함된 파일은 필요한 경우에만 사용자가 직접 판단하여 첨부. 운영자는 문의 처리에 필요하지 않은 원고 제출을 요구하지 않음.

## 사용자 통제

- 프로젝트 데이터: 프로젝트 폴더를 복사·이동·삭제하여 직접 관리
- 앱 설정과 로컬 복구본: 운영체제의 앱 데이터 삭제 기능으로 제거 가능
- 지원 문의 데이터: `qurioturio@gmail.com`으로 열람·정정·삭제·처리정지 요청 가능

## 외부 서비스

운영체제, GitHub, 공식 웹사이트 호스팅 사업자, 사용자가 선택한 외부 백업 서비스와 이메일 사업자의 처리는 각 사업자의 정책 적용. 앱에 분석·광고·결제·클라우드 서비스를 추가할 경우 실제 처리 항목, 목적, 보유 기간과 제3자 제공 여부를 이 안내에 먼저 반영.

## 안전성 원칙

- 인터넷 연결 없이 핵심 집필·열기·내보내기 제공
- 원고 본문과 파일 경로를 원격 진단 서비스로 자동 전송하지 않는 기본값
- 분석·충돌 보고 기능 도입 시 기본 비활성화, 전송 전 고지와 사용자 선택 제공
- 외부 서비스 도입 시 처리 주체, 목적, 항목, 보유 기간과 국외 이전 여부 공개
